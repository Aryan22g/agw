# AGS1 Python SDK

Sign agent requests to the Agent Gateway. Canonicalization, content digests,
nonces and signature bases are handled for you.

## Install

```bash
pip install -e sdks/python
```

## Use

```python
from ags_sdk import Client, GatewayError, load_keystore

rec = load_keystore()  # ~/.ags/credentials.json, written by `ags keygen`

client = Client(
    gateway_url="https://gw.example.com",
    tenant_id=rec["tenantId"],
    agent_id=rec["agentId"],
    private_key=rec["_private_key"],
    key_id=rec["keyId"],
)

response = client.post_json(
    "/v1/tools/github/repos/acme/app/issues",
    {"title": "Filed by an agent"},
)

try:
    result = Client.decode(response)
except GatewayError as err:
    if err.reason == "policy_denied":
        ...          # authenticated, but not permitted to do this
    elif err.is_revoked:
        ...          # credential is finished; re-register rather than retry
    elif err.retryable:
        ...          # transient; a retry mints a fresh nonce
```

Branch on `err.reason`, not on `err.status`: reason codes are a stable
contract, while several distinct reasons deliberately share a status so the
gateway does not become an oracle for which tenants and keys exist.

## Signing without the bundled client

`Client` uses `requests`. To use httpx, aiohttp or anything else, sign
directly:

```python
from ags_sdk import sign_request

headers, body, meta = sign_request(
    method="POST",
    url="https://gw.example.com/v1/tools/github/repos/acme/app/issues",
    tenant_id="tenant-alpha",
    agent_id="agent-support",
    private_key=private_key,
    body=b'{"title":"hi"}',
    content_type="application/json",
)
# `body` is the canonicalized payload; send exactly these bytes, since the
# content digest covers them.
```

## Interoperability

This SDK and the Go SDK are validated against the same conformance corpus at
`pkg/ags1/vectors/ags1-v1.json`. `tests/test_conformance.py` asserts that
Python reproduces every Go-generated signature byte for byte, including the
RFC 8037 A.3 thumbprint vector that pins `kid` derivation.

```bash
python sdks/python/tests/test_conformance.py
```

If these two implementations ever disagree about a single byte, that test
fails — rather than a signature being mysteriously rejected in production.

## Keystores

Keystore files are shared with the `ags` CLI, so a key generated by either
side loads in the other. `load_keystore` refuses a file readable by other
users: a key already exposed to other local accounts should be rotated, not
used.
